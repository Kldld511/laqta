# سياسة الأمان · Security Policy

## النسخ المدعومة · Supported versions
نصلّح الثغرات في آخر نسخة منشورة فقط. حدّث البرنامج قبل ما تبلّغ.
Only the latest release receives security fixes. Please update before reporting.

## العربية
**لا تنشر الثغرة في Issue عام.** بلّغ عنها بشكل خاص:
1. افتح تبويب **Security** في صفحة المشروع، واضغط **Report a vulnerability** إذا كان متاح.
2. إذا ما كان متاح، افتح Issue عادي واكتب إن عندك بلاغ أمني يحتاج تواصل خاص، **بدون** أي تفاصيل عن الثغرة.

اكتب في البلاغ: نسخة البرنامج، وش الثغرة، وكيف تتكرر. بنرد عليك بأسرع وقت، وبنصلّحها في نسخة جديدة ونشكرك فيها إذا تبي.

**ملاحظة:** نزّل البرنامج من صفحة [Releases](../../releases) في هذا المشروع فقط. أي نسخة من مكان ثاني ممكن تكون معدّلة.

## English
**Do not post vulnerabilities in a public issue.** Report them privately:
1. Open the **Security** tab of this repository and click **Report a vulnerability**, if available.
2. If it isn't, open a regular issue saying you have a security report that needs private contact, **without** any details of the issue.

Include the app version, what the vulnerability is, and how to reproduce it. We'll reply as soon as possible, ship a fix in a new release, and credit you if you'd like.

**Note:** only download the app from this repository's [Releases](../../releases) page. Copies from anywhere else may be modified.
